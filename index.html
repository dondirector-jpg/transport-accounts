Transport Accounts

A private internal tool of 5 Star Towing LLC. Last updated November 10, 2026.

Transport Accounts is used only by the owners of 5 Star Towing LLC to read their own business accounts. It is not offered to the public and has no other users.

Privacy policy

What it accesses. When an owner connects one of their own Google accounts, the tool requests read-only access to Gmail, Google Drive (including Docs and Sheets), Google Calendar and Google Contacts. It cannot send email, change, move or delete messages or files, or edit calendars or contacts.

How data is used. Data is read only to run the owners' transport business: finding sign-in codes for the company's own accounts, looking up loads, payments and invoices. It is not used for advertising, not sold, and not shared with anyone.

Where data is kept. Access tokens are stored only in the macOS Keychain on the owners' own computer. Data read from Google is processed on that computer and not stored on any server.

Google API Services User Data Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be removed at any time in the app ("Disconnect") or at myaccount.google.com/permissions.
